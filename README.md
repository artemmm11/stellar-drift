# Звёздный дрейф

Свободный 3D-полёт по процедурной звёздной системе Эльсвет прямо в браузере.

**Открыть:** https://artemmm11.github.io/stellar-drift/

В системе есть газовый гигант Морвен с ледяными кольцами, сквозь которые можно пролететь, орбитальная станция «Перигей», туманность Ткача, комета с ионным и пылевым хвостами и чёрная дыра «Ахерон». Свет вокруг неё искривляется по-настоящему: лучи трассируются в шейдере.

Всё генерируется кодом при загрузке, ни одной текстуры или модели не скачивается. Вся сцена лежит в одном файле `index.html` (Three.js, WebGL 2).

## Управление

| Клавиши | Действие |
|---|---|
| W A S D | полёт |
| Q / E | вниз / вверх |
| Shift | форсаж |
| Мышь | обзор (щёлкните по сцене) |
| 1–6 | точки обзора |
| T | автотур |
| M | звук |
| H | телеметрия |
| Esc | меню |

На телефоне: левый круг — полёт, свайп справа — обзор, кнопки ▲ ▼ — вверх и вниз.
